# LiveDIC

インターバル撮影した画像のリアルタイムDIC（デジタル画像相関法）解析ツール。

フォルダを監視し、新しい画像が来るたびに自動でDIC計算・表示を更新します。

---

## 主な機能

- **2点間モード**: 登録したゲージ点間のひずみをリアルタイムグラフ表示
- **マップモード**: フルフィールドひずみマップをバックグラウンド計算・スライダーで閲覧
- **リアルタイムマップモード**: USBカメラ（1080p/30fps）から直接取得し、引張試験中のひずみマップをライブ表示
  - 前フレーム変位を予測値にした狭探索＋必要時のみ自動拡張、相関低下時の自動再参照
  - カラースケールは試験中固定（0–2 / 5 / 10 / 20 / 40 % プリセット、任意の範囲も指定可）でひずみ集中の成長を可視化
  - CUDA（CuPy）があれば GPU、なければ CPU に自動フォールバック。**GPU なら 1080p・約1,500点で 100 fps 級**（IC-GN 込み）、CPU でも約1,800点で 20 fps 以上
  - タブを開くと自動でカメラを検索し、外付けカメラ（内蔵 Web カメラ以外）を優先して映像が即座に表示される
  - **🔒 フォーカス固定**: 今のピントで固定する（オートフォーカスのピント送りを止める）。解析中でも押せる
  - **サブセット表示**: 追従中のサブセット位置を十字で重ねる。トラッキングの様子がそのまま見える（見失った点は黄色）。表示する割合は 全点 / 1/2 / 1/4 / 1/8 から選択
  - **マップ表示**の ON/OFF。OFF にするとカメラ映像の上に十字だけが出る
  - **別ウィンドウ表示**: 第 2 モニタ・プロジェクタ用。縦向き（90° 回転）に対応、F11 で全画面
  - **記録は解析開始と同時に自動で始まり、停止したときに「すべて残す / マーカーの前後 / 最後の N 分 / 破棄」を選ぶ**（録り忘れが起きず、要らない記録はディスクに残らない）。試験中は「★ マーカー」(M キー) で印を打てる
  - カメラが開けなくなったとき（open に 20 秒以上かかる）は USB を抜き差ししてから「カメラ検索」
- **設定の保存**: サブセット・ステップ・ROI・カメラ・スケール・記録設定などを終了時に保存し、次回起動時に復元（`~/.livedic/settings.json`）
- ZNCC（cv2.matchTemplate使用・高速化済み）
- サブピクセル補間（parabolic / gaussian / spline）
- **IC-GN サブピクセル精密化**（1次形状関数＋B-spline補間。ピクセルロッキングを 0.03px → 0.0005px 級に低減。マップ・リアルタイムモード）
- 固定参照 / 更新参照モード
- 累積ひずみ / 差分ひずみ 切り替え表示
- 手動アライメント（半透明ドラッグ）
- スペックル品質評価（MIG・SSSIGマップ・スペックルサイズ3×3）
- フレームテーブル（荷重・応力手入力、MIG列）
- CSV出力

## ダウンロード・使い方

👉 **[Releases](https://github.com/DefraTanakaLab/LiveDIC/releases)** から最新の `LiveDIC_win64.zip` をダウンロードしてください。

1. zipを解凍する
2. `LiveDIC.exe` をダブルクリックして起動
3. インストール不要・Python不要

> **動作環境**: Windows 10/11 64bit

---

## ソースから実行する場合

```bash
pip install -r requirements.txt
python main.py
```

リアルタイムマップを GPU で動かす場合（NVIDIA GPU、ドライバは CUDA 12 以降対応のもの）:

```bash
pip install "cupy-cuda12x[ctk]"
python check_gpu.py
```

`[ctk]` で CUDA ランタイム・ヘッダも pip から入ります（CUDA Toolkit の別途インストールは不要）。
`check_gpu.py` が「GPU 経路は CPU と一致しています」と出れば OK。
起動時に自動判定され、タブ内の「バックエンド」に GPU 名が表示されます。使えない場合は
自動で CPU に切り替わり、理由がログに出ます。

> **Windows のスマート アプリ コントロールに注意**: 有効だと、pip で入る `nvidia-*` と CuPy の
> `.pyd` が未署名のためブロックされ、GPU が使えません（「バックエンド: GPU」と出たまま
> 1 フレームも処理できない、という状態にはならないよう自動で CPU に落ちます）。
> GPU を使うには Windows セキュリティ →アプリとブラウザー コントロール →
> スマート アプリ コントロール → オフ。

## 記録したデータ

リアルタイムマップの記録は、停止時に「保存」を選ぶと `~/LiveDIC_RT/<日時>/` に残ります。

| ファイル | 中身 |
|---|---|
| `overlay_*.mp4` | 画面に出ていたままの映像（見返し・発表用） |
| `frames.csv` | 毎フレームの時刻・ZNCC・平均/最大ひずみなど。**荷重・応力の列が空で用意**してあるので、入力すれば応力–ひずみ曲線が描ける |
| `disp.bin` | 全フレームの変位場（追記型。試験中にクラッシュしてもそこまで読める） |
| `reference.png` / `grid.npz` / `meta.json` | 参照画像・グリッド座標・解析パラメータ |

ひずみ・ひずみ速度は変位から再現できるので保存していません（11 配列 210 KB/frame → 3 配列 17 KB/frame）。読み出しと再計算は次のとおりです。

```python
import rt_record, dic_core, numpy as np
s = rt_record.read_session(r"C:\Users\<user>\LiveDIC_RT\20261117_013045")
e = dic_core.calc_strain_field(s["X"], s["Y"], s["U"][-1], s["V"][-1], s["meta"]["step"])
print(np.nanmax(e["exx"]) * 100, "%")
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `main.py` | PyQt6 GUI メイン |
| `dic_core.py` | DIC計算コアモジュール |
| `dic_icgn.py` | IC-GN サブピクセル精密化（CuPy/NumPy 共通） |
| `dic_rt.py` | リアルタイムマップ用トラッカー（CuPy/NumPy 共通） |
| `rt_source.py` | USBカメラ取得・フォーカス固定（テスト用の合成ソースも含む） |
| `rt_panel.py` | リアルタイムマップタブ UI |
| `rt_record.py` | 記録（常時一時記録 → 停止時に残すか決める）。保存データの読み出しもここ |
| `settings_store.py` | GUI 設定の保存と復元 |
| `check_gpu.py` | GPU 環境で CuPy 経路の動作・数値一致・速度を確認 |
| `build.bat` | PyInstaller exeビルドスクリプト |
| `make_icon.py` | アイコン生成スクリプト |
| `requirements.txt` | 依存パッケージ |
| `Demo_map_mode/` | マップモード用デモ画像 |
